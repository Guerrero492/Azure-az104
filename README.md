# ☁️ Microsoft Azure Administrator (AZ-104) - Portfolio Práctico

¡Bienvenido a mi repositorio de prácticas y laboratorios de Azure! 

Este repositorio documenta mi camino de preparación para la certificación **Microsoft Azure Administrator (AZ-104)** siguiendo las rutas de aprendizaje oficiales de Microsoft Learn. Aquí encontrarás implementaciones prácticas, scripts (Azure CLI, PowerShell, Bicep, Terraform) y documentación basada en escenarios reales.

## 🎯 Objetivo

Demostrar experiencia práctica (*hands-on*) en la administración, despliegue y configuración de servicios en la nube de Microsoft Azure, aplicando rigurosamente las mejores prácticas de seguridad, alta disponibilidad y gobernanza (Cloud Adoption Framework / Well-Architected Framework).

## 🗂️ Estructura del Repositorio

El contenido está estructurado reflejando las Rutas de Aprendizaje oficiales del AZ-104:

* 🛠️ **[01-Prerequisites-and-ARM-Templates](./01-Prerequisites-and-ARM-Templates/)**: Requisitos previos, herramientas de administración (Cloud Shell, CLI, PowerShell) e Infraestructura como Código mediante Plantillas ARM (JSON).
* 🔐 **[02-Manage-Identities-and-Governance](./02-Manage-Identities-and-Governance/)**: Gestión de Microsoft Entra ID, RBAC, suscripciones y políticas de Azure.
* 💾 **[03-Implement-and-Manage-Storage](./03-Implement-and-Manage-Storage/)**: Cuentas de almacenamiento, Azure Blob Storage, Azure Files y File Sync.
* 🚀 **[04-Deploy-and-Manage-Compute-Resources](./04-Deploy-and-Manage-Compute-Resources/)**: Máquinas Virtuales (VMs), VM Scale Sets, App Services y contenedores.
* 🌐 **[05-Configure-Virtual-Networks](./05-Configure-Virtual-Networks/)**: Redes virtuales (VNets), subredes, NSGs, peering y resolución DNS.
* 📊 **[06-Monitor-and-Backup-Resources](./06-Monitor-and-Backup-Resources/)**: Azure Monitor, Log Analytics, alertas y servicios de copia de seguridad (*Azure Backup*).

Dentro de cada ruta encontrarás una subcarpeta `Guided-Labs/` con los ejercicios prácticos guiados paso a paso.

## 🛠️ Tecnologías y Herramientas Utilizadas

* **Cloud:** Microsoft Azure
* **Infraestructura como Código (IaC):** Plantillas ARM (JSON) / Bicep
* **Automatización:** Azure CLI / Azure PowerShell
* **Control de versiones:** Git & GitHub (siguiendo *Conventional Commits* y *GitHub Flow*)
