# ☁️ Microsoft Azure Administrator (AZ-104) - Portfolio Práctico

¡Bienvenido a mi repositorio de prácticas y laboratorios de Azure! 

Este repositorio documenta mi camino de preparación para la certificación **Microsoft Azure Administrator (AZ-104)**. Aquí encontrarás implementaciones prácticas, scripts (Azure CLI, PowerShell, Bicep, Terraform) y diagramas de arquitectura basados en escenarios del mundo real.

## 🎯 Objetivo

El objetivo de este proyecto es demostrar experiencia práctica (*hands-on*) en la administración, despliegue y configuración de servicios en la nube de Microsoft Azure, aplicando siempre las mejores prácticas de seguridad, alta disponibilidad y optimización de costes.

## 🗂️ Estructura del Repositorio

El contenido está organizado según los dominios oficiales de la certificación AZ-104:

* 🔐 **[01. Identidad y Gobernanza](./01-Identity-and-Governance/)**: Gestión de Microsoft Entra ID, RBAC, Azure Policies y subscripciones.
* 💾 **[02. Almacenamiento](./02-Storage/)**: Azure Storage Accounts, Blob Storage, Azure Files y File Sync.
* 🚀 **[03. Recursos de Proceso (Compute)](./03-Compute/)**: Máquinas Virtuales (VMs), Virtual Machine Scale Sets (VMSS), App Services y contenedores.
* 🌐 **[04. Redes Virtuales](./04-Virtual-Networking/)**: VNets, NSGs, Peering, Load Balancers, Application Gateway y Azure DNS.
* 📊 **[05. Monitorización y Copias de Seguridad](./05-Monitoring-and-Backup/)**: Azure Monitor, Log Analytics, alertas y Azure Backup.

## 🛠️ Herramientas y Tecnologías Utilizadas

* **Cloud:** Microsoft Azure
* **Infraestructura como Código (IaC):** Azure Bicep / Terraform / Plantillas ARM
* **Scripting:** Azure CLI / PowerShell
* **Documentación:** Markdown & Mermaid (Diagramas)
