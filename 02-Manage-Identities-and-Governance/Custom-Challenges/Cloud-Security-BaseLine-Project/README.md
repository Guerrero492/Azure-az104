# 🛡️ Azure Cloud Security Baseline: Gobierno e Identidades

**Objetivo:** Diseñar e implementar una arquitectura de seguridad base (Security Baseline) en Microsoft Azure, integrando controles de gobierno, gestión de identidades (IAM) y protección contra amenazas mediante la aplicación del Principio de Mínimo Privilegio (PoLP).

## 🏗️ Fases del Proyecto

### Fase 1: Gobierno Corporativo y Cumplimiento (Azure Policy)
Implementación de barreras de protección (guardrails) para asegurar que la infraestructura cumpla con la soberanía de datos y los estándares de etiquetado de la compañía antes del despliegue.
* **Estado:** ⏳ Pendiente

### Fase 2: Arquitectura de Control de Acceso (RBAC)
Diseño de una jerarquía de grupos (Auditores vs. Desarrolladores) y asignación granular de roles para prevenir el movimiento lateral y aislar los entornos de trabajo.
* **Estado:** ⏳ Pendiente

### Fase 3: Resiliencia de Identidad y Anti-Phishing (SSPR & Branding)
Mitigación de ataques de ingeniería social mediante personalización visual de confianza y reducción de la superficie de ataque en la mesa de ayuda (Helpdesk) mediante flujos de recuperación autónomos.
* **Estado:** ⏳ Pendiente

### Fase 4: Auditoría y Trazabilidad Forense (Activity Log)
Extracción y análisis de la telemetría operativa para garantizar el no repudio de los cambios administrativos y facilitar la respuesta a incidentes (IR).
* **Estado:** ⏳ Pendiente
